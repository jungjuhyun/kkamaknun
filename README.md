# kkamaknun (까막눈)

일본어 학습·실험 유튜브 채널 「까막눈」의 계획·실측·도구 저장소.

채널의 기본 문법:
> 문제를 찾는다 → 필요한 만큼 배운다 → 실제로 써먹어본다 → 결과를 확인한다 → 다음 문제로 간다.

성장·수익화·지속 가능한 생산성까지 함께 판단한다.

## 기획 운영 방식 V2

주요 기획은 사용자가 다시 `공격해봐`라고 말하기 전에 자체 검수를 끝낸다.

```text
맥락 잠금
→ 문제 정의
→ 서로 다른 경쟁안 생성
→ 빠른 경쟁
→ RED TEAM A: 시청자/콘텐츠
→ 수리
→ RED TEAM B: 제작/사업/증거/기회비용
→ 필요 시 사전 기준 TEST
→ 최종 경쟁
→ GO / TEST / HOLD / KILL
→ 사용자 결정
→ 실제 결과 후 교정
```

각 주요 단계가 끝날 때도 `Stage Exit Attack`으로 방금 만든 결함을 다시 확인한다.
세부 절차는 [PLANNING_PROCESS.md](PLANNING_PROCESS.md).

## 핵심 운영 원칙

- 결론만 저장하지 않고 **왜 그렇게 판단했는지**를 보존한다.
- 동시에 과거 판단을 맹신하지 않고 **예측과 실제 결과를 비교해 교정**한다.
- 현재 사실을 여러 문서에 반복 복사하지 않는다.
- 같은 모델의 자기공격을 `독립 검토`라고 과장하지 않는다.
- 공정 자체가 실제 제작보다 무거워지면 실행 가능한 테스트 쪽으로 돌아간다.

기존 `틀어만 두세요` 애니 반복듣기 포맷은 폐기하지 않았으며, 현재 첫 콘텐츠 이후의 저비용 생산 엔진 후보로 보관한다.
