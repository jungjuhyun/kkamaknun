# kkamaknun (까막눈)

일본어 학습 유튜브 채널 「까막눈」의 계획·실측·도구 저장소.

채널의 주인공은 만드는 사람 본인이다. 강의가 아니라 **학습·실험 로그** —
배운다 → 써먹는다 → 성공/실패를 확인한다 → 다음 단계로 간다.
성장·수익화·지속 가능한 생산성도 함께 판단한다.

## 지금 하는 것

**첫 콘텐츠 확정이 최우선.**

현재 질문은:

> 애니·일본 콘텐츠를 오래 본 사람은 자막 없이 실제 애니 한 편의 이야기를 어디까지 이해할 수 있을까?

유력 포맷은 자막 OFF 시청 → 이해한 이야기 먼저 잠금 → 자막/정답 검증.
`귀멸의 칼날`이 현재 유력 후보지만 작품/화수는 최종 확정 전이다.

기존 `틀어만 두세요` 애니 반복듣기 포맷은 폐기하지 않았고 **후속 저비용 생산 엔진 후보**로 보관한다.
