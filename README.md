# kkamaknun

까막눈 프로젝트의 clean-sheet 운영 저장소.

현재 `main`에서 agent가 필요에 따라 참고할 핵심 문서는 여섯 개다.

1. `AGENTS.md` — 어디를 언제 읽을지
2. `STATE.md` — 지금 어디까지 왔고 다음에 무엇을 할지
3. `PROJECT_CONTEXT.md` — 오래 유지되는 프로젝트 정체성·목표
4. `USER_PROFILE.md` — 의사결정에 필요한 안정적 사용자 취향·성향
5. `PLAYBOOK.md` — 판단과 실행 원칙
6. `FIRST_VIDEO.md` — 현재 첫 콘텐츠 세부

`CLAUDE.md`의 immutable 지침은 그대로 보존한다.

모든 문서를 일괄 preload하지 않는다. 사용자 적합성이 실제 판단을 바꿀 때만 `USER_PROFILE.md`를 읽는다.

과거 저장소 상태는 backup branch와 git history에만 남아 있으며, 현재 작업에서는 기본 참조하지 않는다.
