# kkamaknun

애니메이션으로 배우는 일본 여행·일상 회화 유튜브 채널.

일본 가서 말할 수 있게 해주는 것을 판다. 애니는 소재가 아니라 교보재다.

## 공정

```
상황 정한다
  → 그 상황 회화 목록을 남의 콘텐츠(쇼츠·앱·교재)에서 긁는다
  → 코어 패턴으로 분해한다
  → 자막 검색 API로 실제 대사를 찾는다
  → 유명작에서 걸린 것만 남기고 나머지는 버린다
  → 한 편으로 묶는다
```

**버리는 것이 공정의 핵심이다.** 교재 목차를 채울 의무가 없다.

## 도구

```
python 도구/매칭_코어패턴.py     # 상황별 문장 → 유명작 확보 개수
python 도구/대사뽑기.py          # 확보된 표현의 실제 대사·번역·작품
```

재료는 ImmersionKit(`apiv2.immersionkit.com`). 인증 없이 쓴다.
응답에 문장·후리가나·영어번역·정지컷 jpg·성우 음성 mp3·작품명이 들어 있다. **동영상은 없다.**

## 현재 상태

영상 0편. 재료 확보만 실측으로 끝난 상태다.

| | |
|---|---|
| 식당편 | 15문장 중 **15개** 유명작 확보 |
| 편의점·가게편 | 12문장 중 **11개** 확보 |
| 3편 이후 | 미확인. 만들기 전에 매 편 재야 한다 |
