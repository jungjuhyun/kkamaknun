# kkamaknun (까막눈)

일본어 학습 유튜브 채널 「까막눈」의 계획·실측·도구 저장소.

채널의 주인공은 만드는 사람 본인이다. 강의가 아니라 **학습 로그** —
배운다 → 써먹는다 → 성공/실패를 확인한다 → 다음 단계로 간다.

## 지금 하는 것

**파는 것은 내가 성장하는 것이고, 눈금은 JLPT다** (2026-08-20 확정).
N5 → N1이 그대로 시즌이고, 시험 날짜가 외부 데드라인이 된다.
쉐도잉은 주력 코너가 아니라 **성장 수단 1번**이다. 수단은 무제한이고 교체 가능하다.

**수단 1번 = 애니 교보재.** 공부하면서 직접 교보재를 만든다.
귀로는 아는데 정확한 용법을 모르는 표현을 찾아보고, 알게 된 것을 곁들인다.
한 편 = 한 뜻 또는 한 문법 항목. 그 파생 버전들을 여러 인기작에서 성우 원음으로 모은다.

커리큘럼은 **JLPT 문법 항목 ∩ 애니 재고**다. 전수 커버는 목표가 아니다 —
안 걸리는 문법을 버리는 것 자체가 상품이다("이건 안 외워도 됩니다").

## 도구

```
python 도구/표현모으기.py 안녕 おはよう こんにちは やあ   # 버전들이 작품군별 몇 컷인지
python 도구/대사가져오기.py おはよう 8                    # 실제 대사·번역·이미지·음성 주소
python 도구/나데시코검색.py ありがとう                    # 문장 검색 → 대사·작품·클립 주소
python 도구/자막받기.py "Jujutsu Kaisen" [받기]           # 회차 자막 srt
python 도구/유튜브실적.py @채널핸들                       # 채널 편별 조회수

# 문법 항목도 같은 도구로 잰다 (exactMatch는 부분일치다)
python 도구/표현모으기.py N5문법 てください ましょう ながら 前に
```

작품 목록·작품군 정의는 [도구/작품군.py](도구/작품군.py) 한 곳에만 있다.

**주의: 표현모으기·대사가져오기는 ImmersionKit 전용이고, 거기엔 라프텔 인기 100위 중
9편밖에 없다.** 원피스·주술회전·체인소맨·진격거가 빠진다 — 결과는 **항목별 재고의 하한치**로만 쓴다.
작품 간 비교는 kitsunekko 자막 전수 카운트로 따로 잰다
([실측/JLPT_N5문법_재고.txt](실측/JLPT_N5문법_재고.txt) [6]번).
