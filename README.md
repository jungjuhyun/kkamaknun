# kkamaknun (까막눈)

일본어 학습 유튜브 채널 「까막눈」의 계획·실측·도구 저장소.

채널의 주인공은 만드는 사람 본인이다. 강의가 아니라 **학습 로그** —
배운다 → 써먹는다 → 성공/실패를 확인한다 → 다음 단계로 간다.

## 지금 하는 것

**애니 쉐도잉 코너.** 편성계획의 주역 확장 코너다. 문자 해설(카타카나·히라가나) 코너는 2026-08-19 제외했다.

한 편 = 한 뜻. 「안녕」이면 안녕·안녕~·안녕하십니까 같은 여러 말투 버전을
여러 인기 애니에서 성우 원음으로 모아 한 편을 만든다. 작품군(소년만화끼리·극장판끼리)으로 묶는다.

## 도구

```
python 도구/표현모으기.py 안녕 おはよう こんにちは やあ   # 버전들이 작품군별 몇 컷인지
python 도구/대사가져오기.py おはよう 8                    # 실제 대사·번역·이미지·음성 주소
python 도구/나데시코검색.py ありがとう                    # 문장 검색 → 대사·작품·클립 주소
python 도구/자막받기.py "Jujutsu Kaisen" [받기]           # 회차 자막 srt
python 도구/유튜브실적.py @채널핸들                       # 채널 편별 조회수
```

작품 목록·작품군 정의는 [도구/작품군.py](도구/작품군.py) 한 곳에만 있다.
