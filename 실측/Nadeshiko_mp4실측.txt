Nadeshiko 문장 클립(mp4) 실측 (2026-08-19)

쟁점: 사이트 Save 버튼에는 Image+Audio / Image / Audio만 있고 영상 다운로드가 없다.
그럼 mp4는 뭐냐 — 각 문장 카드의 재생 버튼이 트는 원본 파일이다.
검색 결과 페이지 HTML 안에 문장마다 cdn.nadeshiko.co 주소가 박혀 있고, 직접 받으면 받아진다.

주의:
- 공식 기능이 아니다. 사이트가 주소 체계를 바꾸면 막힌다. 화면에서는 Save(Image+Audio)도 쓸 수 있다.
- 검색 API(api.nadeshiko.co/v1/*)는 전부 로그인 요구(401). 검색 결과 "페이지"는 로그인 없이 열린다.
- 수록작 검색창(en/media?query=)은 고장 — 있는 작품도 없다고 나온다.
  수록 여부는 실측/Nadeshiko_수록작_317.txt로 확인하라.
