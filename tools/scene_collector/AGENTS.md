# AGENTS.md — 애니 표현 장면 수집기

이 지침은 `tools/scene_collector` 아래의 모든 작업에 적용한다.
저장소 루트의 현재 owner 문서와 함께 따르되, 작업 요청의 범위를 넘지 않는다.

## 개발 기준

- Python 3.11 이상을 지원한다.
- 프로젝트와 개발 의존성은 uv로 관리한다.
- 새 의존성을 추가하기 전에 현재 의존성이나 Python 표준 라이브러리로 해결할 수 있는지 확인한다.
- 필요가 확인되지 않은 파일, 계층, 공급자 추상화, 대체 구현을 미리 만들지 않는다.

## 경로와 비밀정보

- 사용자 환경의 절대경로와 SSD 드라이브 문자를 코드나 예제에 하드코딩하지 않는다.
- 작업 데이터 위치는 사용자가 지정하는 설정값으로 다룬다.
- 실제 API 키와 비밀정보를 코드, 문서, 시험 자료, 예제 파일에 넣지 않는다.
- `.env.example`에는 빈 값이나 명백한 예시 값만 둔다.

## 외부 서비스와 시험

- Nadeshiko HTTP 통신, 인증, 재시도, 페이지 순회를 재구현하지 않고 공식 Python SDK를 사용한다.
- AI 회사별 통신 계층을 직접 만들지 않고 구조화 출력에는 Instructor 사용을 우선한다.
- 일반 자동시험은 인터넷 없이 실행할 수 있어야 하며 실제 AI 또는 Nadeshiko API를 호출하지 않는다.
- 실제 연결 시험은 명시적으로 활성화한 경우에만 실행한다.

## 변경 범위와 완료 확인

- 해당 작업에서 명시적으로 요구하지 않는 한 `tools/scene_collector` 밖의 파일을 수정하지 않는다.
- 현재 작업 범위 밖에서 발견한 개선을 같은 변경에 끼워 넣지 않는다.
- 작업을 마치기 전에 이 디렉터리에서 다음 명령을 실행한다.

```text
uv sync
uv run pytest
uv run ruff check .
```
