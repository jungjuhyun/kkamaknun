# EP1 시험 초안 — 1차 촬영본 실제 사건만으로 만든 1화 구성

이 초안의 사건은 촬영본에서 사용자가 판정한 실제 사건이다. 나레이션은 초안이다.

시험 기획이다. 완성본이 아니며 판정은 사용자가 한다.

근거: `STATE.md` → `PLAYBOOK.md` 4·6·7장 → `materials/ep1_take1/후보표.md`(맨 위 사용자 판정 절) → `materials/ep1_take1/발언표.md` → `tools/harness/EP1_LOCK.json`.
사건은 사용자 판정 "사건" 7개만 쓴다. 사건 번호는 후보표 사용자 판정 절의 원래 번호(1~9)다. 판정 "아님" 2개(part_04 05:45–05:52 자세 고침, part_05 03:29–07:07 졸림)는 쓰지 않는다. 새 사건·가상 대사·없는 반응은 만들지 않는다.

## A · B (잠금 원문)

- A: 20년 이상 애니를 봤지만 일본어를 제대로 공부해본 적은 없는 사람
- B: 체인소 맨: 레제편을 한국어 자막 없이 보고, 자기 귀에 실제로 무엇이 남아 있는지 확인한다.
- C: 핵심 감상(20년 좋아한 시간이 사람한테 이렇게 남는구나) → 자기투영(나도 비슷한 상태인가) → 후속 호기심(제대로 공부하면 어떻게 될까). `FIRST_VIDEO.md`의 3층 구조를 그대로 쓴다.

시각 표기: `part_XX 파일 안 시각` = 사용자 판정 기준. 괄호 안은 6개 파트를 이어 붙인 전체 타임코드(후보표·발언표 기준).

## 2. 콘텐츠 각 후보

**각 후보: 제목은 못 읽는데, 질문에는 웃는다 — 자막을 끄고 나서야 보인 20년의 자리**

이유:
1. 사건 1(제목 앞에서 멈춤)과 사건 5(질문을 알아듣고 웃음)가 실제로 있고, 둘의 낙차가 정지 화면과 웃음으로 화면에 보인다. 만든 낙차가 아니다.
2. 진단 분류 없이 사건 순서만으로 핵심 감상(오래 본 게 이렇게 남는구나)이 생기고, 사건 2·5에서 자기투영, 사건 4·8에서 후속 호기심이 이어진다.
3. 사건 3·6·8이 있어서 사용자가 끝까지 작품 보는 사람으로 남는다. 마지막 3분 침묵(사건 8)이 실험이 사라지는 결말 역할을 하므로, 채널이 강의·진단 카테고리로 잠기지 않는다.

## 4. 확인 못 한 것

- 사건 2·5·6·8의 실제 소리(웃음 소리, 억양, 타이밍)는 정지 화면과 발언표로만 봤다. 원본 클립으로 다시 확인해야 한다.
- 발언표의 `사용자 발언 추정 [불명]` 구간(사건 2의 `계획... 아니네`, 사건 5의 `나 외에 / 좋아하는 사람 있겠지?`)은 애니 대사와 겹쳐 있어 단어가 정확하지 않을 수 있다. 나레이션에 인용한 발언은 `사용자 발언` 판정 구간 위주로 골랐다.
- 사건 4·8이 `이해한 몰입`인지 `못 알아들은 채 화면만 본 것`인지는 화면으로 구분할 수 없다. 이 초안은 그 불확실성 자체를 후속 호기심으로 두었고, 이해도를 단정하지 않았다.
- C가 실제 시청자에게 생기는지는 예상 댓글·공유 문구로 아직 검증하지 않았다.
