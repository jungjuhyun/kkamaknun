# 현재 실행 계획 — 0화 YouTube 기획 실행 신뢰성 POC

상태: **종료** — 10단계 사용자 품질 판정 FAIL(기획 품질 실패). 11·12단계는 `plans/HARNESS_HANDOFF.md`로 이관.
기준일: 2026-09-02

이 문서는 이번 **`0화 YouTube 기획 실행 신뢰성 POC` 전용 실행 문서**다.
- 다른 프로젝트 계획을 이 문서에 덧붙이지 않는다.
- 이후 새로운 계획의 공용 `CURRENT_PLAN` 파일로 재사용하지 않는다.
- 이번 POC가 종료되면 이 문서의 ACTIVE 실행 문서 역할도 종료한다.
- POC 종료 후 장기적으로 남길 결과만 적절한 owner/`STATE.md`에 반영하고, 이 일회성 문서의 정리 여부는 그때 별도로 판단한다.

단계 정의는 `tools/harness/PIPELINE.yaml`, 진행 상태는 `tools/harness/STATE.json`이 owner다. 이 문서에는 체크박스를 두지 않는다.

## 목표

이번 POC에서 증명할 것은 하나다.

> **repo의 current truth와 기획 공정을 실제 실행 단계에서 유지하면서, 현재 확보 가능한 근거와 검증된 콘텐츠 원칙을 활용해 `유튜브라는 플랫폼에서의 성공 확률`을 최대한 높인 0화 촬영 전 가상 완성본을 만들 수 있는가.**

여기서 `유튜브라는 플랫폼에서의 성공 확률`은 결과 보장이 아니라 다음을 동시에 높이는 방향의 기획을 뜻한다.

- 노출됐을 때 선택될 이유
- 클릭 후 계속 볼 이유
- 시청 후 만족과 기억에 남을 이유
- 채널과 인물에 대한 후속 시청·구독 이유
- 장기적으로 반복 가능한 채널 경쟁력

단순히 오류가 없는 것도 부족하고, 단순히 촬영 가능한 초안만 나와도 부족하다. **current truth 준수 + YouTube 경쟁력을 고려한 기획 품질**을 둘 다 통과해야 한다.

- 촬영 방식(진단용 프로토콜)이 콘텐츠 엔진으로 잘못 승격됐다.

- AI 내부 RED TEAM #2가 패키징과 C를 PASS로 판정한 것은 오판이다.

새 가상 완성본을 다시 만들지 않는다. 다음 순서는 `STATE.md`가 가리키는 대로 실제 촬영물 관찰부터다.
