# 현재 실행 계획 — 0화 YouTube 기획 실행 신뢰성 POC

상태: **종료** — 10단계 사용자 품질 판정 FAIL(기획 품질 실패). 11·12단계는 `plans/HARNESS_HANDOFF.md`로 이관.
기준일: 2026-09-02

이 문서는 이번 **`0화 YouTube 기획 실행 신뢰성 POC` 전용 실행 문서**다.
- 다른 프로젝트 계획을 이 문서에 덧붙이지 않는다.
- 이후 새로운 계획의 공용 `CURRENT_PLAN` 파일로 재사용하지 않는다.
- 이번 POC가 종료되면 이 문서의 ACTIVE 실행 문서 역할도 종료한다.
- POC 종료 후 장기적으로 남길 결과만 적절한 owner/`STATE.md`에 반영하고, 이 일회성 문서의 정리 여부는 그때 별도로 판단한다.

단계 정의는 `tools/harness/PIPELINE.yaml`, 진행 상태는 `tools/harness/STATE.json`이 owner다. 이 문서에는 체크박스를 두지 않는다.

## 목표

이번 POC에서 증명할 것은 하나다.

> **repo의 current truth와 기획 공정을 실제 실행 단계에서 유지하면서, 현재 확보 가능한 근거와 검증된 콘텐츠 원칙을 활용해 `유튜브라는 플랫폼에서의 성공 확률`을 최대한 높인 0화 촬영 전 가상 완성본을 만들 수 있는가.**

여기서 `유튜브라는 플랫폼에서의 성공 확률`은 결과 보장이 아니라 다음을 동시에 높이는 방향의 기획을 뜻한다.

- 노출됐을 때 선택될 이유
- 클릭 후 계속 볼 이유
- 시청 후 만족과 기억에 남을 이유
- 채널과 인물에 대한 후속 시청·구독 이유
- 장기적으로 반복 가능한 채널 경쟁력

단순히 오류가 없는 것도 부족하고, 단순히 촬영 가능한 초안만 나와도 부족하다. **current truth 준수 + YouTube 경쟁력을 고려한 기획 품질**을 둘 다 통과해야 한다.

# 세부 계획

## 1. 이번 작업의 RUN CONTRACT 잠금

새 규칙을 만드는 것이 아니라 `STATE.md + FIRST_VIDEO.md + PLAYBOOK.md`에서 이번 0화 작업에 필요한 것만 추출해 작업 계약으로 고정한다.

### LOCKED — 변경 금지

- A: `20년 이상 애니를 봤지만 일본어를 제대로 공부해본 적은 없는 사람`
- B: `체인소 맨: 레제편을 한국어 자막 없이 보고, 자기 귀에 실제로 무엇이 남아 있는지 확인한다.`
- C: `FIRST_VIDEO.md`의 현재 3층 감상 구조
- 레제편으로 실제 테스트 촬영이 진행되었다는 사실
- 1차 약 82분 촬영물이 이미 존재한다는 사실
- 0화 진단용 촬영 프로토콜이 이미 채택됐다는 사실

### AVAILABLE — 실제 확인된 자료

- 현재 repo owner 문서
- 현재 owner에 기록된 청해 관찰과 사전 검증 결과
- 기존 촬영물의 존재와 현재 기록된 촬영 상태

### UNAVAILABLE — 있다고 주장하면 HARD FAIL

- 실제로 확보하지 못한 레제편 일본어 전체 자막 본문
- 실제로 확인하지 않은 특정 촬영 장면의 구체 내용
- 아직 검증되지 않은 최종 촬영 반응이나 결과

### SIMULATION ALLOWED

촬영 전 가상 완성본을 위해 다음은 적극적으로 가정할 수 있다.

- 특정 장면에서 정확히 알아듣는 사건
- 부분적으로 알아듣는 사건
- 뜻은 이해하지만 정확한 소리를 못 잡는 사건
- 소리는 잡지만 실제 표기·어휘 형태를 모르는 사건
- 문맥 때문에 자신 있게 오해하는 사건
- 예상보다 어려운 대사를 맞히는 사건
- 웃음·당황·확신·번복 등의 반응
- 사건의 순서와 영상 내 배치

이것들은 **촬영 전 시뮬레이션**이며 실제 프로젝트 사실이 아니다.

## 10. 사용자 품질 판정

### 판정 결과 — 기획 품질 실패

- 제목·썸네일 / 패키징: **FAIL**. 사용자는 현재 패키지를 실제로 사용하고 싶지 않다고 판정했다.

- 촬영 방식(진단용 프로토콜)이 콘텐츠 엔진으로 잘못 승격됐다.
- 진단 분류(소리/뜻/문맥/문자)가 C를 지배했다.
