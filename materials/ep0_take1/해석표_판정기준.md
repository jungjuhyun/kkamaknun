# 해석표 판정 기준

0화 1차 촬영본 해석표에서 사용자 발언 하나에 판정 하나를 붙이는 규칙이다.
판정 대상 표는 `chainsawman_take_tables_v2.xlsx`의 `해석표` 탭이다.

## 왜 바꿨나

전에 쓰던 라벨은 13가지였다.
`맞음`, `얼추 맞음`, `의미 맞음`, `의미는 맞음`, `뜻은 맞음`, `부분 맞음`, `부분`, `단어만 맞춤`, `거의 틀림`, `틀림`, `모름`, `대조 불가`, 빈칸.

문제는 셋이다.

- 앞의 다섯은 서로 무엇이 다른지 정하는 규칙이 없었다.
- `부분 맞음`과 `부분`이 같은 뜻으로 나뉘어 있었다.
- `모름`이 두 가지에 붙었다. 안 들린다고 말한 행과, 소리는 잡았는데 뜻을 모르는 행이다.

## 판정 7가지

| 판정 | 언제 붙이나 |
|---|---|
| **다 맞음** | 대사가 전하는 뜻을 맞게 말했다. 표현이 달라도 뜻이 같으면 여기 넣는다. |
| **반 맞음** | 뜻의 일부만 맞다. 나머지는 빠졌거나 틀렸다. |
| **단어만** | 문장 뜻이 아니라 단어 하나만 알아들었다. |
| **소리만** | 소리는 맞게 잡았으나 뜻은 말하지 않았다. |
| **틀림** | 뜻을 틀리게 말했다. |
| **못 알아들음** | 뜻을 하나도 말하지 못하고 안 들린다고 말했다. |
| **판정 안 함** | 대사를 알아들으려 한 말이 아니다. 화면 반응, 인물 평가, 감상, 신음이 여기 들어간다. |

## 붙이는 순서

위에서부터 차례로 확인하고, 처음 걸리는 것 하나만 붙인다.

1. 대사나 화면 글자를 알아들으려 한 말인가? 아니면 → **판정 안 함**
2. 뜻을 하나도 말하지 않았나?
   소리는 잡았으면 → **소리만**
   안 들린다고 했으면 → **못 알아들음**
3. 말한 뜻이 단어 하나뿐인가? → **단어만**
4. 뜻이 다 맞나? → **다 맞음**
5. 일부만 맞나? → **반 맞음**
6. 다 틀렸나? → **틀림**

## 판정할 때 지키는 것

- 귀로 들은 대사와 눈으로 읽은 화면 글자를 같은 기준으로 잰다.
- 뜻이 통하는 표현 차이는 내리지 않는다. 심장과 마음, 체인과 체인소가 그렇다.
- 뜻이 달라지면 내린다. 절대 와 줘를 절대 와야 한다는 의무로 바꾼 것이 그렇다.
- 일부만 말하고 나머지를 모르겠다고 한 행은 **못 알아들음**이 아니라 **반 맞음**이다. 못 알아들음은 뜻을 하나도 말하지 못한 행에만 붙인다.

## 따라 말함 열

일본어 소리를 그대로 따라 말한 행에 `O`를 붙였다.
판정과는 따로 본다. 소리를 정확히 들었다는 별개의 표시다.

뜻은 몰라도 소리는 정확히 잡은 행이 있고, 소리는 안 따라 하고 뜻만 맞게 말한 행이 있다.
이 둘을 판정 하나에 섞으면 다시 애매해지므로 열을 나눴다.

## 집계

91행 기준이다.

| 판정 | 행 수 |
|---|---|
| 다 맞음 | 49 |
| 반 맞음 | 15 |
| 판정 안 함 | 17 |
| 못 알아들음 | 4 |
| 소리만 | 3 |
| 단어만 | 2 |
| 틀림 | 1 |

판정 안 함 17행을 뺀 74행이 실제 청해 판정 대상이다.
그중 다 맞음이 49행이다.
