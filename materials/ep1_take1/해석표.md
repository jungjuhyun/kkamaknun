# 해석표 — 1화 1차 촬영본, 사용자 해석 발언 vs 애니 대사

대상: `후보표.md` E절(발언 기반 19개)과 `발언표.md`에서 사용자가 대사의 뜻·소리를 말한 구간(해석 발언) 전부. `파일`·`파일 안 시각`은 사용자가 가진 6분할 proxy(part_00~05) 기준이며 각 파일의 0초부터 잰 시각이다(사용자 발언 시작). 괄호 안 애니 대사 시각과 비고의 시각도 같은 파일 기준이고, 다른 파일이면 앞에 파일명을 붙였다. 마지막 열 `전체 시각`은 6개를 이어 붙인 타임코드로 발언표·후보표와 맞춰 볼 때 쓴다. 파일 경계(오디오 길이 누적): part_01 908.35s, part_02 1808.35s, part_03 2708.35s, part_04 3608.35s, part_05 4508.35s.

애니 대사 출처: faster-whisper large-v3 일본어 강제 통과(tx_ja). 이 통과는 **사용자의 한국어까지 일본어로 되받아 적는다**(사용자 발언과 같은 시각에 뜻이 같은 일본어 줄이 나옴). 그래서 사용자 발언보다 앞서 나오고 자연스러운 일본어인 줄만 애니 대사로 채택했고, 그런 줄이 없거나 받아적기가 파편이면 `대조 불가`로 두고 지어내지 않았다. 공식 일본어 자막 본문과 대조한 것이 아니다.

임시 판정 기준(확정은 사용자가 한다):
- **맞음**: 사용자가 말한 뜻이 채택한 애니 대사의 뜻과 같다.

- **틀림**: 뜻이 다르다.
- **대조 불가**: 애니 대사 받아적기가 없거나 파편·저신뢰이거나, 사용자 발언이 해석이 아닌 반응이거나, 사용자 육성 여부가 불명하다.

- 공식 일본어 자막 본문과 대조하지 않았다. 애니 대사 열은 음성 인식 결과이며 이름(デンジ→伝授官, マキマ→牧間)과 동음 단어(一歩/一本, 港湾/公安)에서 틀릴 수 있다.

- 사용자 육성 여부가 불명한 `추정` 구간은 판정하지 않았다.
