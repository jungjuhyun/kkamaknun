# 2026-08-20 심야 — 세션 정리

ChatGPT 대화 검토에서 시작해 채널 축을 갈아엎은 세션이다.
대화는 PC 사이를 이전하지 않으므로 여기 남긴다. 결정만 보려면 [진행상태.md](../진행상태.md)로.

## 1. 시작 — ChatGPT 대화 검토

첨부된 ChatGPT 로그(2026-08-20)를 읽었다. 사용자 발화 14개 중 12개가 파일 첨부 + 한 줄이라
실제 논쟁은 KOF 하나뿐이었다.

**ChatGPT가 도달한 결론**: 채널 축을 "귀로만 20년 쌓인 일본어를 제대로 된 일본어로 바꾸면서
닫혀 있던 일본을 하나씩 여는 사람"으로 잡고, 첫 3편을 ① 얼마나 알아들을까 ② 글자로 보면 얼마나
읽을까 ③ 말하면 어디서 무너질까로.

**KOF는 완전 제외 확정** — 메인 소재도, 증거도, 보조 컷으로도 안 쓴다. 지금 세대와 안 맞는다.

**남길 만한 것 하나** — ChatGPT가 KOF 지적에 물러서며 낸 필터:
> "나한테 의미가 있느냐" + "지금 20대가 제목만 보고도 궁금하냐"
> 둘 다 통과해야 메인 영상, 하나만 통과하면 영상 안의 재료.

## 2. 축이 바뀐 과정 (본인 발언 순서대로)

1. **"쉐도잉도 주력이 아니고 서사도 주력이 아니다. 주된 건 내가 성장하는 것.
   성장한 일본어로 일본에 가는 것이 목표. 배우는 수단은 무한정."**
   → 채널 정의가 확정됐다. 코너가 목적이던 구조가 뒤집혔다.

2. **"중간쯤에 헬로톡이나 디스코드에 들어가는 거지, 중간점검이지.
   일본행은 종착점이 아니라 과정이고, 가면 브이로그·여행·소통·문화로 뻗어나가는 거지."**
   → 경로가 확정됐다. (AI가 "일본행이 종착점이면 채널이 닫힌다"고 지적만 하고 시즌2를 안 낸 것을
   여기서 지적받았다 — CLAUDE.md에 규칙으로 넣었다.)

3. **"내가 했던 방식을 멤버십으로 돌리면 되는 거지. '나는 이렇게 공부했다' 정도의 팁."**
   → AI가 "교육 채널 전환"과 "멤버십 수익화"를 한 덩어리로 걷어찼던 것을 정정.
   멤버십은 본편을 안 건드린다.

4. **"쉐도잉은 내가 공부하면서 직접 교보재를 만드는 느낌이다."** (います 예시)
   → 이게 채널의 "속"이 됐다. 비출연 충돌도 여기서 풀렸다.

5. **"애니에만 있다면 방대하지. 드라마·영화까지 가면 무궁무진하지."**
   → 실사 확장. 재고는 이미 Nadeshiko에 들어가 있었다.

6. **"애니로 딴 JLPT 3급, 이런 식으로 제목이 하나 생기겠지."**
   → **눈금이 확정됐다.** 이 세션에서 제일 큰 것.

7. **"떨어지면 다시 보면 되지 무엇이 문제인가?"**
   → 불합격 = 종료라는 AI의 전제를 깼다. 재응시는 같은 시험 반복이라 성장 증거가 더 명확해진다.

8. **"왜 원피스 나루토 이런 건 없지?"**
   → N5 실측의 표본 구멍을 잡아냈다. 작품 순위 결론을 철회했다.

## 3. 확인한 사실 (이 세션에서 새로 판독)

- **Nadeshiko 317편에 실사가 이미 있다** — 알리스 인 보더랜드 · 고질라 마이너스 원 ·
  마카나이 · 나체 감독 · 17.3 about a sex · 아메쿠 M.D. · 닌자와 암살자
- **ImmersionKit `exactMatch=true`는 부분일치다** — ください 3,138건이 증거.
  문장 전체가 그 단어일 리 없다. 그래서 문법 항목 검색이 된다
- **CLAUDE.md에 이미 문법 재고가 하나 적혀 있었다** — `〜てください` 수천 건.
  통문장 검색 실패 사건의 기록이 사실은 문법 패턴 재고 실측이었다
- **재료양 실측의 안 읽힌 패턴** — 애니는 감정·서사 어휘가 두껍고 접객·정중 어휘가 얇다
  (わかりません 3 / どういたしまして 7 / いらっしゃいませ 10 vs どこ 645). 실사가 그 구멍을 메운다
- **제작자 실적 읽기가 4년 전 기준이었다** — "병목은 기획·나레이션"인데

## 4. AI가 틀렸고 정정한 것

| 틀린 것 | 정정 |
|---|---|
| 일본행이 종착점이면 채널이 닫힌다 (지적만 하고 끝) | 시즌2를 냈어야 했다. 계획 1-3에 후보 4개 추가 |
| 조사 비용이 새 부담이다 | 조사는 답이 있는 검색, 선별은 답이 없는 판단. 병목은 선별 하나 |
| 교육 채널 전환은 권하지 않는다 → 멤버십까지 같이 기각 | 다른 것이다. 멤버십은 본편을 안 건드린다 |
| 불합격에 대비 설계가 필요하다 | 다시 보면 된다. 오히려 성적표가 데이터가 더 많다 |
| "수백 컷 이상은 한 편으로 못 묶는다" | 기준은 컷 수가 아니라 뜻이 하나로 묶이는가다 |
| 재고 상위와 견인력이 어긋난다 (실측으로 확인됨) | **철회.** 큰 IP를 빼고 잰 결과였다 |
| "안 걸리는 문법을 버리는 게 상품" | N5는 24/24라 버릴 게 없다. 상급으로 위치 이동 |
