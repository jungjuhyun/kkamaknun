# CONTINUATION_LOADER.md

아래 문장과 생성된 active continuation handoff를 새 Chat에 함께 제공한다.

> 첨부한 active continuation handoff를 처음부터 끝까지 읽어라. Current repository truth 확인은 현재 ChatGPT Project instruction을 별도로 따르고, 충돌하면 current repository owner를 우선하라. Handoff는 conversation-only context로 사용하라. 다음 사용자 발화를 이전 Chat의 바로 다음 발화로 취급하고, 요청이 없으면 장황한 recap을 기본 출력하지 마라.
